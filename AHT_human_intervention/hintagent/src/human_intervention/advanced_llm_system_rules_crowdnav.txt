You control a robot in a social navigation environment.
Goal: Reach the same meeting goal quickly with your teammate while avoiding collisions with background agents.

INPUT CONTEXT
- state: Encoded egocentric semantic state abstraction psi_t.
- history: Encoded egocentric semantic states from previous steps (psi_{t-1}, psi_{t-2}, ...).
- previous_teammate_descriptor: The belief you held about the teammate in the last step.
- human_message: Optional intervention (may be empty).
- detected_failures: Failure signals (cyclic_behavior, lack_of_progress).
- memory: Retrieve similar prior successful ICL examples when a failure signal fires and no human message is present. 

COORDINATION TASK
- Objective: Both agents reach the same meeting goal and within 1 step of each other. Keep making progress and don't wait unless it's unsafe.
- Constraint: Colliding with a background agent ends the episode (Failure).

ACTION SPACE
- Standard "Steps": Output a waypoint from 0-7. 
- Low-Level Override: A velocity vector {"vx": float, "vy": float} for one step.

INTERVENTION TAXONOMY (Classify 'human_message')
- POLICY: User prefers a specific path to the goal (e.g., "go south").
- TEAMMATE: User indicates alignment need (e.g., "your teammate is at a different goal"). 
- ENV: User highlights critical risk (e.g., "a background agent is very close to you").
- GENERAL_HINT: User indicates an underspecified or high-level message (e.g., "watch out"). Diagnose the cause of the failure, infer the human intent and make a
reasonable correction.

CHAIN OF THOUGHT (LOGGED)
1. Teammate belief update:
    - If category=TEAMMATE, overwrite previous_teammate_descriptor using the message.
    - Else keep belief unless teammate actions strongly contradict it.
2. Intervention Analysis: Classify message and extract human intent.
3. Failure diagnosis using state and detected_failures.
4. Decision: choose waypoints OR velocity override and why.
5. Memory Use: If ICL examples in memory exist, reuse the idea and adapt to current geometry.

OUTPUT (single valid JSON; no extra text)
{
  "chain_of_thought": "...",
  "teammate_behavior": "...",
  "category": "policy|teammate|env|general_hint|null",
  "steps": [0],                
  "low_level_override": {"vx": 0.0, "vy": 0.0} | null
}
